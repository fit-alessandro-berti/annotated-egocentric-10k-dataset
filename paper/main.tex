\abstract{Manual factory work often leaves few records in information systems. We present a construction design and data resource that connect egocentric video to retrospective process analysis. The design first narrates recordings, aggregates descriptions across workers, and induces shared factory vocabularies. It then assigns interval events using those vocabularies and consolidates the logs. Pretrained model parameters remain fixed, while the vocabulary adapts to each available factory corpus. Generation uses no task-specific fine-tuning or labeled event examples; assessment uses an author audit and an analyst-defined category map. The linked artifacts include 322 per-video logs with 10{,}698 events from 59 workers in six factories. All events have the required fields and permitted labels. An existing audit finds full transcript support for 36 of 42 sampled events and partial support for six; this does not establish accuracy against video. Descriptive calculations assign 10.8\% of retained summed event duration in one factory to defect patching, already described in its report. They also show why a zero transport category can coexist with 101 recorded transport events: categories are assigned from process context. Worked examples explain how vocabulary, label assignment, event boundaries, and analytical mapping affect measurements. The inferred resource supports inspection and hypothesis generation; video accuracy, causal diagnoses, and intervention effects remain unmeasured.}
\keyword{process mining; inferred event logs; egocentric video; measurement; data quality; manufacturing; foundation models}
